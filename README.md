# 🎮 React Jokenpô

Aplicação web interativa baseada no clássico jogo **Pedra, Papel e Tesoura (Jokenpô)**, desenvolvida com **React** e **TypeScript**.

## 🚀 Sobre O Projeto

O projeto tem como objetivo proporcionar uma experiência interativa e divertida, aplicando conceitos modernos de desenvolvimento front-end, como componentização, gerenciamento de estado e estilização responsiva.

## 🛠️ Tecnologias Utilizadas

* **React** (Biblioteca JavaScript para construção de interfaces)
* **TypeScript** (Tipagem estática para maior segurança e escalabilidade)
* **CSS3** para estilização e layout

## 📦 Estrutura do Projeto

```text
ReactJokenpo/
├── public/       → Arquivos públicos e ícones
├── src/          → Código fonte (componentes, estilos e lógica do jogo)
├── package.json  → Dependências e scripts do projeto
└── tsconfig.json → Configurações do TypeScript
```
⚙️ Scripts Disponíveis
No diretório do projeto, você pode executar os seguintes comandos no terminal:

npm start
Executa a aplicação no modo de desenvolvimento.

Abra http://localhost:3000 para visualizá-la no navegador. A página será recarregada automaticamente se você fizer edições.

npm test
Inicia o executor de testes interativo.

npm run build
Empacota a aplicação para produção na pasta build. O código é otimizado para a melhor performance, compactado e pronto para deploy.

▶️ Como Executar Localmente
Certifique-se de ter o Node.js instalado.

Clone o repositório:

Bash
git clone [https://github.com/C4d5/ReactJokenpo.git](https://github.com/C4d5/ReactJokenpo.git)
Entre na pasta do projeto:

Bash
cd ReactJokenpo
Instale as dependências:

Bash
npm install
Inicie o servidor de desenvolvimento:

Bash
npm start
